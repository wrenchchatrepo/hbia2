The LookML parameter reference is organized by the [major structures of a LookML project](/looker/docs/lookml-terms-and-concepts#major_lookml_structures), from the highest-level structures to the most detailed components of a LookML project:

  * [Project manifest parameters](/looker/docs/reference/param-project-manifest)
  * [Model parameters](/looker/docs/reference/param-model)
  * [Explore parameters](/looker/docs/reference/param-explore)
  * [Join parameters](/looker/docs/reference/param-join)
  * [View parameters](/looker/docs/reference/param-view)
  * [Field parameters](/looker/docs/reference/param-field)
  * [Dimension, filter, and parameter types](/looker/docs/reference/param-dimension-filter-parameter-types)
  * [Measure types](/looker/docs/reference/param-measure-types)

**Note:** [LookML dashboard parameters](/looker/docs/reference/param-lookml-dashboard) are described along with user-defined dashboards in the Looker documentation. See the [LookML dashboard overview](/looker/docs/reference/lookml-dashboard-overview) for information.
