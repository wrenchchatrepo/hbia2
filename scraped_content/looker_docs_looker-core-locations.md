# https://cloud.google.com/looker/docs/looker-core-locations

Depth: 3

Within a Google Cloud console project, Looker (Google Cloud core) instances can be created in one of many [locations](/about/locations). These represent the geographical regions where a Looker (Google Cloud core) instance is hosted. Select the region that matches the region in the subscription contract, which is where the [quota for your project](/docs/quota_detail/view_manage) is allocated.

To see a list of the locations that are available for use in Looker (Google Cloud core) for different parts of the world, select one of the following options:
