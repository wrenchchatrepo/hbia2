# https://cloud.google.com/looker/docs/visualization-types

Depth: 3

**Note:** This page describes visualization options for Looker. For information about Looker Studio visualizations, see [Types of charts in Looker Studio](/looker/docs/studio/types-of-charts-in-looker-studio).

Looker has many visualizations that you can use to make sense of your data. Each type of visualization has different settings that you can use to customize its appearance. The following links provide information about each visualization and its settings.

> For information about choosing a visualization type that best fits your data, see the [Selecting an effective data visualization](/looker/docs/visualization-guide) documentation page.

## Chart Config Editor

If you have the [`can_override_vis_config` permission](/looker/docs/admin-panel-users-roles#can_override_vis_config), you can use the [Chart Config Editor](/looker/docs/chart-config-editor) to create the following visualization types:

  * [Bullet](/looker/docs/bullet-chart)
  * [Solid gauge](/looker/docs/solid-gauge)
  * [Streamgraph](/looker/docs/streamgraph)
  * [Treemap](/looker/docs/treemap)
  * [Sankey](/looker/docs/sankey)
  * [Dependency wheel](/looker/docs/dependency-wheel)
  * [Venn diagram](/looker/docs/venn)
  * [Sunburst](/looker/docs/sunburst)
  * [Item](/looker/docs/item)

## Custom visualizations

> This page lists Looker's built-in visualization types. If your Looker developer has added any [custom visualization](/looker/docs/admin-panel-platform-visualizations) types to Looker, you may see additional options in the ellipsis (...) menu in the Visualization bar of the Explore page.
