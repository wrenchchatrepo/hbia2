# https://cloud.google.com/looker/docs/admin-panel-general-pages

Depth: 3

These pages appear under the **General** section of Looker's **Admin** menu:

  * [Settings](/looker/docs/admin-panel-general-settings): Set instance-wide options in Looker's general settings panel.
  * [Labs](/looker/docs/admin-panel-general-labs): Enable and disable beta and experimental Looker features.
  * [Legacy Features](/looker/docs/legacy-feature-schedule): Enable, disable, and prepare to migrate away from outdated Looker features. This option appears only if legacy features are available for your instance.
  * [Homepage](/looker/docs/admin-panel-general-homepage): Set a default homepage for your instance. Customize Looker's appearance, including removing links and Looker logos. This option appears only if Looker has enabled the private label feature for your instance. [Contact a Google Cloud sales specialist](https://cloud.google.com/contact) for pricing and additional information.
  * [Internal Help Resources](/looker/docs/admin-panel-general-internal-help): Configure a list of resources your company offers to support Looker users.
  * [Support Access](/looker/docs/admin-panel-general-support-access): Manage Looker analysts' access to your Looker instance.
  * [Localization](/looker/docs/admin-panel-general-localization): Set your company's default instance locale and number format.
  * [Export](/looker/docs/admin-panel-export) Configure export during [self-service migration](/looker/docs/looker-core-self-service-migration) of an instance from Looker (original) to [Looker (Google Cloud core)](/looker/docs/looker-core-overview). (Original-to-core migration must be enabled by Looker. [Contact a Google Cloud sales specialist](/contact) to enable this feature.)
