# https://cloud.google.com/looker/docs/looker-core-user-authentication

Depth: 3

Customers can authenticate to a Looker (Google Cloud core) instance using one of the following methods:

  * [OAuth](/looker/docs/looker-core-oauth-authentication)
  * [SAML](/looker/docs/admin-panel-authentication-saml)
  * [OpenID Connect](/looker/docs/admin-panel-authentication-openid-connect)

**Note:** When using third-party identity providers, customer responsibility for controlling access and permissions for users of your Looker instance is outlined in Google's [Our shared security partnership](/looker/product/security) page.
