# https://cloud.google.com/looker/docs/admin-panel-alerts-and-schedules-pages

Depth: 3

These pages appear under the **Alerts & Schedules** section of Looker's **Admin** menu:

  * [Alerts](/looker/docs/admin-panel-alerts-and-schedules-alerts): View, filter by, edit, and delete dashboard tile alerts. Navigate to the dashboard containing the tile with the alert.
  * [Alert History](/looker/docs/admin-panel-alerts-and-schedules-alert-history): View running, complete, and failed alerts.
  * [Schedules](/looker/docs/admin-panel-alerts-and-schedules-schedule): View, reassign, and delete data delivery schedules.
  * [Schedule History](/looker/docs/admin-panel-alerts-and-schedules-schedule-history): View history of and troubleshoot scheduled data deliveries.
  * [Scheduled Emails](/looker/docs/admin-panel-alerts-and-schedules-scheduled-emails): Manage email delivery settings to include only links back to Looker content, only Looker data, or both links and data. Monitor content being sent from Looker to email addresses with domains external to Looker.
