# https://cloud.google.com/looker/docs/studio/enterprise-administrator-feature-overview

Depth: 3

**Note:** Organization administrators manage Looker Studio's enterprise features using the Google Admin console.

As an organization administrator, you can review and control how Looker Studio is used in your organization. [Cloud Identity](/identity/docs/set-up-cloud-identity-admin) and [Google Workspace administrators](https://support.google.com/a/answer/2405986) can manage many administrative tasks by using the Looker Studio **Enterprise admin** panel or by utilizing Looker Studio's Cloud Identity integration. Google Workspace administrators can also [transfer ownership](https://support.google.com/a/answer/33314) of Looker Studio assets.

> [Learn more about Looker Studio enterprise features](https://support.google.com/a/answer/9706918).
