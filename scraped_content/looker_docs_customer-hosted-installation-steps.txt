This page explains how to install the Looker application for customers who are hosting an [on-premises](/looker/docs/glossary#customer-hosted) Looker deployment. Throughout our documentation, we refer to these as "customer-hosted" deployments.

We also offer the option for Looker to host your Looker deployment. Throughout our documentation we refer to these as "[Looker-hosted](/looker/docs/glossary#looker-hosted)" deployments. Using a Looker-hosted instance greatly reduces the effort required to [install](/looker/docs/looker-hosted-installation-steps), configure, and maintain the Looker application, because Looker handles all necessary IT functions that are related to the Looker application for you.

**Note:** Hosting the Looker application is independent of where your data resides; data always remains in-database and is not copied to the Looker instance. Some Looker features are not available for customer-hosted deployments, or they may require additional configuration or software. To learn more about feature differences between the two hosted options, see the [Choosing a hosting option for a Looker (original) instance](/looker/docs/choosing-hosting-option) documentation page.

Complete the following steps:

  1. Install Looker:

     * [Add Looker to your server](/looker/docs/installing-looker-application).

     * [Configure Looker startup options](/looker/docs/startup-options).

     * [Configure your SSL certificate for proper HTTPS](/looker/docs/ssl-certificate-for-proper-https).

     * [Consider port forwarding for a cleaner URL](/looker/docs/port-forwarding).

     * [Allow Looker support to access your instance](/looker/docs/support-access-customer-hosted-deployment).

     * [Set up Looker monitoring](/looker/docs/monitoring-looker).

     * [Set up a MySQL backend database](/looker/docs/migrating-looker-backend-db-to-mysql).

**Note:** We recommend that all new customer-hosted instances set up a MySQL backend database rather than use the default HyperSQL database.
     * [Set up Looker backups](/looker/docs/creating-backups).

     * [Ensure that Looker can access necessary services](/looker/docs/outbound-port-requirements).

     * [Install rendering software](/looker/docs/installation-of-rendering-software).

     * [Determine if your Looker instance can accommodate the Looker Action Hub](/looker/docs/action-hub#considerations_for_customer-hosted_instances).

  2. [Enable secure database access](/looker/docs/enabling-secure-db-access).

  3. [Configure your database for Looker](/looker/docs/dialects).

  4. [Connect Looker to your database](/looker/docs/connecting-to-your-db).

  5. [Test your database connectivity](/looker/docs/testing-db-connectivity).

  6. [Configure Looker sign-in options](/looker/docs/getting-started-with-users).

Once your instance is set up, you're ready to [get started with development](/looker/docs/data-modeling).
